# Quick Start

In this guide, you will learn how to authenticate and make your first API call to FlowCMS.

## 1. Get your API Key

Once your waitlist access is approved and you've created a workspace, navigate to the **Settings > API Keys** section of your dashboard.
Generate a new API key. **Save it securely**, as it will not be shown again.

## 2. Make your first request

All API requests must be authenticated using the `Authorization` header and versioned using `X-API-Version`.

```bash
curl -X GET "https://getflowcms.com/api/v1/entries?type=blog_post" \
  -H "Authorization: Bearer flw_your_api_key_here" \
  -H "X-API-Version: 1"
```
