# Welcome to FlowCMS

FlowCMS is a modern, open-source headless CMS built specifically for developers and teams who want structured content without the enterprise bloat. 

## Why FlowCMS?

We built FlowCMS to solve three main problems:
1. **Predictability:** Type-safe APIs powered by Prisma.
2. **Speed:** Lightweight, modular, and designed to run anywhere via Docker.
3. **Developer Experience:** No proprietary query languages. Just pure, predictable REST endpoints.

## Who is this for?

- **Indie Hackers** building Next.js or React applications.
- **Agencies** looking for a white-label CMS solution for their clients.
- **Founders** who want to own their content infrastructure without vendor lock-in.
