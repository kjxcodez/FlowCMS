# Environment Variables

FlowCMS uses environment variables for database connections, authentication, background workers, notifications, storage, and billing integrations. Configure these in a `.env` file at the project root.

## Required Variables

### Database
- `DATABASE_URL` — Connection string for PostgreSQL (used for connection pooling).
- `DIRECT_URL` — Direct connection string for PostgreSQL (used for database schema migrations).

### Authentication (Better Auth)
- `BETTER_AUTH_SECRET` — A secure, random 32-character string used to sign user sessions and cookies.
- `BETTER_AUTH_URL` — The base canonical URL of your application (e.g. `http://localhost:3000` or `https://cms.yourdomain.com`).

### Core Settings
- `NEXT_PUBLIC_APP_URL` — The public-facing URL of the application. Used for generating client-side links and webhooks.

### Redis (Upstash)
Used for API rate-limiting, usage logs tracking, and caching.
- `UPSTASH_REDIS_REST_URL` — The Upstash Redis REST API URL.
- `UPSTASH_REDIS_REST_TOKEN` — The Upstash Redis REST API Token.

### Email (Resend)
- `RESEND_API_KEY` — Your Resend API key for sending transactional emails, verifications, and invitations.

### Webhook Queue (Upstash QStash)
Required for background queuing and reliable delivery of webhooks.
- `QSTASH_TOKEN` — Upstash QStash authorization token.
- `QSTASH_CURRENT_SIGNING_KEY` — Current signing key for QStash webhook callbacks.
- `QSTASH_NEXT_SIGNING_KEY` — Next/rotation signing key for QStash webhook callbacks.

## Optional Variables

### Media Storage
- `STORAGE_PROVIDER` — The file storage provider to use. Options: `local`, `supabase`. Defaults to `local` (offline-friendly filesystem uploads in the `/public/uploads` directory).
- `NEXT_PUBLIC_SUPABASE_URL` — Required if `STORAGE_PROVIDER=supabase`. The Supabase project URL.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` — Required if `STORAGE_PROVIDER=supabase`. The Supabase anonymous API key.
- `SUPABASE_SERVICE_KEY` — Required if `STORAGE_PROVIDER=supabase`. The Supabase service role key (bypasses RLS).

### Transactional Mail
- `RESEND_FROM_EMAIL` — The email address to send emails from. Defaults to `FlowCMS <no-reply@mail.getflowcms.com>`.

### OAuth / Social Providers
- `GOOGLE_CLIENT_ID` — Google OAuth Client ID for social login.
- `GOOGLE_CLIENT_SECRET` — Google OAuth Client Secret for social login.

### Access Control
- `ADMIN_EMAILS` — Comma-separated list of emails that automatically bypass onboarding waitlists and are granted platform admin rights.

### Billing (Razorpay Integration)
Required if you are offering paid plans (Pro, Agency) via Razorpay.
- `RAZORPAY_KEY_ID` — Razorpay API key ID.
- `RAZORPAY_KEY_SECRET` — Razorpay API key secret.
- `RAZORPAY_PRO_MONTHLY_PLAN_ID` — Razorpay monthly plan ID for Pro plan.
- `RAZORPAY_PRO_ANNUAL_PLAN_ID` — Razorpay annual plan ID for Pro plan.
- `RAZORPAY_AGENCY_MONTHLY_PLAN_ID` — Razorpay monthly plan ID for Agency plan.
- `RAZORPAY_AGENCY_ANNUAL_PLAN_ID` — Razorpay annual plan ID for Agency plan.

### Cache Management
- `CLOUDFLARE_ZONE_ID` — Optional Cloudflare Zone ID for automatic edge cache purging.
- `CLOUDFLARE_API_TOKEN` — Optional Cloudflare API Token for edge cache purging.

### AI Integration
- `GEMINI_API_KEY` — Google Gemini API key used to power AI assistance in content modeling or block generation.

### Observability & Error Tracking
- `SENTRY_DSN` / `NEXT_PUBLIC_SENTRY_DSN` — DSN endpoints for Sentry error tracking on server-side and client-side respectively.

## Example `.env` File

```bash
# Database
DATABASE_URL="postgresql://flowcms:flowcms_pass@localhost:5432/flowcms?schema=public"
DIRECT_URL="postgresql://flowcms:flowcms_pass@localhost:5432/flowcms?schema=public"

# Better Auth & Core App
BETTER_AUTH_SECRET="some-super-random-32-char-string-here"
BETTER_AUTH_URL="http://localhost:3000"
NEXT_PUBLIC_APP_URL="http://localhost:3000"

# Redis Caching & Rate Limiting
UPSTASH_REDIS_REST_URL="https://your-redis-instance.upstash.io"
UPSTASH_REDIS_REST_TOKEN="your_redis_token_here"

# Webhook queue
QSTASH_TOKEN="qstash_token"
QSTASH_CURRENT_SIGNING_KEY="current_signing_key"
QSTASH_NEXT_SIGNING_KEY="next_signing_key"

# Resend Mailer
RESEND_API_KEY="re_123456789"
RESEND_FROM_EMAIL="FlowCMS <no-reply@mail.getflowcms.com>"

# Optional Storage (Default is local)
STORAGE_PROVIDER="local"

# Platform Admin
ADMIN_EMAILS="admin@yourdomain.com,owner@yourdomain.com"
```
