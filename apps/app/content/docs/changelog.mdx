# Changelog

## v0.1.0 - Waitlist Launch

**May 2026**

Welcome to the first release of FlowCMS! This release focuses on core infrastructure and waitlist onboarding.

### Features
- **Headless Editor:** Block-based visual editor with Tiptap.
- **Content Modeling:** Dynamic schema generation and relationships.
- **REST API (v1):** Fast, predictable endpoints for Entries and Content Types.
- **Self-Hosting:** Full Docker support with PostgreSQL and Redis.
- **Waitlist Access:** Priority queue system with referral tracking.

### Security
- Implemented Three-Layer Auth Protection Model.
- Atomic waitlist consumption using Prisma transactions.
- Idempotent webhook and email processing.
