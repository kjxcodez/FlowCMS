# Collections API

The Collections API allows you to retrieve the schema definitions for your content types. These definitions are useful for dynamically generating layouts, forms, or checking fields on your frontend.

## List Collections

Retrieve a list of all collections defined in your workspace.

### Request

```http
GET /api/v1/collections
Authorization: Bearer <your_api_key>
X-API-Version: 1
```

### Required Scope

- `read:collections`

### Response

```json
{
  "success": true,
  "data": [
    {
      "id": "cm0col1234567890",
      "workspaceId": "cm0ws1234567890",
```

## Fetch a Single Collection

Retrieve the details and field schema of a specific collection by its slug.

### Request

```http
GET /api/v1/collections/{slug}
Authorization: Bearer <your_api_key>
X-API-Version: 1
```

### Required Scope

- `read:collections`

### Parameters

- `slug` (in path): The slug of the collection.

### Response

```json
{
  "success": true,
  "data": {
    "id": "cm0col1234567890",
    "workspaceId": "cm0ws1234567890",
    "name": "Blog Posts",

    "mode": "STRUCTURED",
    "fields": [
      {
        "id": "fld_1",

      {
        "id": "fld_2",

        "multiple": false
      }
    ],
    "createdAt": "2026-05-09T10:00:00Z",
    "updatedAt": "2026-05-10T12:00:00Z"
```
